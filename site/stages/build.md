Build writes the learning content to the assessments. It is the most labour-intensive stage but the least risky, because structure and evidence are already settled.

## What happens

- Write the learning materials, activities and resources into the approved skeletons.
- Keep each content block traced to the task and descriptors it prepares the learner for.
- Write for the cohort: reading level, examples and access needs from the Discover profiles.

## At the gate, ask

- Is it accurate and current? Has a subject-matter expert checked it?
- Is there content that prepares for nothing assessed, or a task nothing prepares for?
- Can the named cohort read and use it, including learners using assistive technology?
