## Comment on the model

Open an [issue on GitHub]({{ site.issues }}) for anything that is wrong, unclear or missing. For now, GitHub issues are the only channel; a form or an address may follow. Useful comments say:

- which page or stage the comment is about;
- what you would expect instead, and why;
- where you work, if it helps (vocational, higher education, schools, workplace learning, independent teaching), so we can see how the model transfers.

## Share a case

The model's practitioner grounding is concentrated in one sector and one country. A case from elsewhere, where a stage did or did not fit, is the most useful contribution you can make. Please remove anything that identifies a learner, a client or an employer before you share it.

## Run a study

The [research agenda](/research/) lists six claims that need testing and the measures that would test them. If you can run one, open an issue and we will link your work from this site.

## How this site is made

The site's source, and the ways of working behind it, are [on GitHub]({{ site.repo }}). Before each release, a panel of reviewers reads the changed pages, and the records are kept in the repository. Every change is listed on the [changes](/changes/) page.
